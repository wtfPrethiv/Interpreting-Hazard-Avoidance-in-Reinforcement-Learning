# Experiment plan

1. Define hazard dynamics, observations, and appearance-only interventions.
2. Specify training and held-out appearances before training.
3. Validate that appearance changes preserve rewards, layout, and dynamics.
4. Train baseline policies across multiple seeds.
5. Measure returns, success rates, and hazard encounters on each appearance condition.
6. Collect activations and fit probes with independent training and evaluation splits.
7. Test causal claims using activation patching and ablations with matched controls.
8. Record uncertainty, failure cases, configurations, seeds, code revisions, and checkpoints.
